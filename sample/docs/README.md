# Sample Docs

Test fixtures for `cmapdetector` and `scriptdetector` packages.
Generated by [`cmd/gen-samples`](../../cmd/gen-samples/main.go) — re-run at any time:

```bash
go run ./cmd/gen-samples/
```

## File Descriptions

### Baseline / Clean

1. **`clean.pdf`**
   PDF 1.7, Helvetica, `WinAnsiEncoding`.
   - `cmapdetector`: `HasProblematicCMap = false`, `DetectedBy = None`
   - `scriptdetector`: `HasThreat = false`

2. **`Surat.pdf`**
   PDF 1.6, Times-Roman, `MacRomanEncoding`. Represents the XRef-stream era
   (extractor does not parse XRef streams, but the byte scanner is unaffected).
   - `cmapdetector`: `HasProblematicCMap = false`, `DetectedBy = None`
   - `scriptdetector`: `HasThreat = false`

3. **`injected.pdf`**
   Contains an inline `/CMapName /Adobe-Identity-UCS` stream. The name is
   **not** in `knownProblematicCMaps`, so the detector must not flag this file.
   Used as a false-positive guard.
   - `cmapdetector`: `HasProblematicCMap = false`, `DetectedBy = None`
   - `scriptdetector`: `HasThreat = false`

---

### CMap Issue

4. **`malformed.pdf`** — `MEDIUM`
   `AdobeSongStd-Light` font with `/Encoding /UniGB-UTF16-H`. The canonical
   case that causes iTextPDF to throw:
   ```
   com.itextpdf.io.font.cmap.UniGB-UTF16-H was not found
   ```
   - `cmapdetector`: `HasProblematicCMap = true`, `FoundCMaps = [UniGB-UTF16-H]`, `DetectedBy = BytesScan`
   - `scriptdetector`: `HasThreat = false`

---

### Script Issue

5. **`form.pdf`** — `MEDIUM`
   JotForm-style PDF with `/S /JavaScript` form field validation. No CJK CMap.
   JavaScript detection is in scope for `scriptdetector` only.
   - `cmapdetector`: `HasProblematicCMap = false`
   - `scriptdetector`: `HasThreat = true`, `Threats = JavaScript`, `MaxSeverity = MEDIUM`

---

### Severity-Labelled Fixtures

6. **`severity_low.pdf`** — `LOW`
   Contains only a `/EmbeddedFile` entry (a `readme.txt` attachment). May be
   benign in PDF/A contexts; warrants inspection.
   - `cmapdetector`: `HasProblematicCMap = false`
   - `scriptdetector`: `HasThreat = true`, `Threats = EmbeddedFile`, `MaxSeverity = LOW`

7. **`severity_medium.pdf`** — `MEDIUM`
   `KozMinPro-Regular` with `/Encoding /UniJIS-UTF16-H` (Japanese) plus a
   `/S /JavaScript` open-document action. Both detectors fire.
   - `cmapdetector`: `HasProblematicCMap = true`, `FoundCMaps = [UniJIS-UTF16-H]`
   - `scriptdetector`: `HasThreat = true`, `Threats = JavaScript`, `MaxSeverity = MEDIUM`

8. **`severity_high.pdf`** — `HIGH`
   `/Launch` action targeting `calc.exe` combined with a `String.fromCharCode`
   obfuscation pattern. No CJK CMap.
   - `cmapdetector`: `HasProblematicCMap = false`
   - `scriptdetector`: `HasThreat = true`, `Threats = LaunchAction+Obfuscation`, `MaxSeverity = HIGH`

9. **`severity_critical.pdf`** — `CRITICAL`
   Combines the most severe indicators from both detectors:
   - `eval(unescape(...))` — payload decodes to `"function noop(){}"` (no-op, safe)
   - `ActiveXObject('WScript.Shell')` + `cmd.exe /c echo test` — pattern only, no live payload
   - `AdobeSongStd-Light` with `/Encoding /UniGB-UTF16-H`

   - `cmapdetector`: `HasProblematicCMap = true`, `FoundCMaps = [UniGB-UTF16-H]`
   - `scriptdetector`: `HasThreat = true`, `Threats = JavaScript+Obfuscation+ShellExecution`, `MaxSeverity = CRITICAL`

---

### Invalid / Non-PDF

10. **`fileCorrupt.pdf`**
    256 bytes of deterministic pseudo-random data with no `%PDF-` header.
    Simulates an encrypted or otherwise unrecognisable binary.
    - `cmapdetector`: returns `ErrNotPDF`
    - `scriptdetector`: returns `ErrNotPDF`

11. **`fake_pdf.pdf`**
    PNG magic bytes (`\x89PNG...`) renamed to `.pdf`. Simulates a file-type
    spoofing attempt.
    - `cmapdetector`: returns `ErrNotPDF`
    - `scriptdetector`: returns `ErrNotPDF`

---

### Structural Edge Cases (`sample/`)

These two files live one level up in `sample/` and are referenced by the
`cmapdetector` root fixture tests.

12. **`../corrupted.pdf`**
    Western TrueType font (`Arial`, `WinAnsiEncoding`) with a deliberately
    truncated XRef table. The corruption is at the structural level — not
    CMap-related — so `cmapdetector` must not flag it.
    - `cmapdetector`: `HasProblematicCMap = false`, `DetectedBy = None`

13. **`../Kalibrator.pdf`**
    Inline `/CMapName /A-B-C` — a custom name that is **not** in
    `knownProblematicCMaps`. Verifies that only predefined CJK CMaps are flagged.
    - `cmapdetector`: `HasProblematicCMap = false`, `DetectedBy = None`
